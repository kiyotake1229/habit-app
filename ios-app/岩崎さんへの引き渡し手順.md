# 岩崎さんへ — 「コツコツ」iOSアプリ ビルド・申請手順

岩崎さん

習慣＆タスク管理アプリ「コツコツ」のiOSプロジェクトです。
**Xcodeで開いてビルド → App Store申請** まで進められる状態になっています。

必要な作業は大きく2つです。

1. Xcodeで開いて、署名（Team）を自社アカウントに設定してビルド → 3章
2. App Store Connect にアップロードして審査に提出 → 4章

申請時に入力するアプリ名・説明文・キーワードなどは、4章に**下書きを用意してあります**。
そのまま使っていただいても、修正いただいても構いません。

ご不明な点があればお知らせください。

## 2. 必要な環境

- macOS（Xcode 26 が動くもの。**下の表の範囲**。Mac の macOS は「アップルメニュー → この Mac について」で確かめる）

  | Mac の macOS | 使う Xcode |
  |---|---|
  | macOS Tahoe 26.2 〜 26.x | **Xcode 26.6**（GitHub Actions でビルドを確かめている版） |
  | macOS Sequoia 15.6 〜 15.x | Xcode 26.3（Sequoia で動く Xcode 26 の最後の版） |
  | **macOS 27 以降** | **ビルドの前に清武へ連絡してください**（下の注意） |

  - Apple の対応表（https://developer.apple.com/support/xcode/ 、2026-11-06 に確認）では、Xcode 26.x が動く macOS は「Tahoe 26.x まで」で、macOS 27 は入っていません
  - macOS 27 の Mac で Xcode 26 が使えないときに、**代わりに Xcode 27 でビルドして申請しないでください**（下の理由で、起動しないアプリになるおそれがあります）
- **Xcode 26.x**（GitHub Actions の Xcode 26.6 でビルドが通ることを確認済み）
  - **Xcode 27 は使わないでください。** このプロジェクトは Capacitor 7 の作りのままで、iOS の「UIScene」というしくみに対応していません。Apple は、Xcode 27（iOS 27 の SDK）でビルドしたアプリは UIScene に対応していないと起動しない、としています。Xcode 27 が必須になる前（2027年春の予定）に清武が対応します
  - Mac App Store からは最新の Xcode 27 が入ります。Xcode 26.x は [Apple Developer の More Downloads](https://developer.apple.com/download/all/) から入れてください（Apple アカウントでサインイン →「Xcode 26」で検索。複数の Xcode は名前を変えて並べて置けます）
  - Xcode 27 も入っている Mac では、コマンドで使う Xcode を `sudo xcode-select -s /Applications/Xcode_26.app` で切り替え（名前は入れた Xcode 26 に合わせる）、プロジェクトも `open -a /Applications/Xcode_26.app ios/App/App.xcworkspace` のように Xcode 26 で開いてください
  - 初回起動時に iOS のプラットフォーム（シミュレータなど）の追加を求められたら、追加してください
- Node.js 20 以降（`node -v` で確認。Capacitor 7 は 20 以上が必要で、18 では `npx cap` が動きません）
- CocoaPods（`brew install cocoapods`）

## 3. ビルド手順

このフォルダ（`ios-app/`）で、以下を順に実行してください。

```bash
# 1) 依存パッケージを取得
npm install

# 2) Xcodeで開く
open ios/App/App.xcworkspace
```

> CocoaPods（Pods）の統合は**完了済み**です。`pod install` は不要ですが、
> 実行しても問題ありません（`npm install` は必須：Podsがnode_modulesを参照するため）。

> **注意**: 必ず `App.xcworkspace` を開いてください（`App.xcodeproj` ではありません）。

### Xcode上での設定

1. 左ペインで **App** を選択 → **Signing & Capabilities** タブ
2. **Team** に自社のApple Developerアカウントを選択（"Automatically manage signing" はON）
3. 必要に応じて **Bundle Identifier** を自社のものに変更
4. **General** タブで **Version**（例: 1.0.0）と **Build**（例: 1）を設定

### 動作確認

- 上部のデバイス選択から実機またはシミュレータを選び ▶ で起動
- 称号カードを共有して、共有シートで「画像を保存」を選ぶと、初めてのときだけ写真への追加の許可を求めるダイアログが出ます（説明文:「称号カードの画像を「写真」に保存するときに使います。」）。許可すると「写真」に保存されます

## 4. App Store申請

1. Xcode: **Product → Archive**
2. Organizerが開いたら **Distribute App → App Store Connect** でアップロード
3. [App Store Connect](https://appstoreconnect.apple.com) でアプリ情報を入力して審査提出

### 申請情報（下書き）

**アプリ名**
```
コツコツ - 称号が育つ習慣アプリ
```

**サブタイトル（30字以内）**
```
続けると育ち、サボると錆びる。
```

**説明文**
```
「コツコツ」は、続けるほど「あなた」が育つ習慣アプリです。

■ 称号が育つ
習慣を続けると「読書の常連」「運動の達人」のような称号に進化します。数字ではなく、自分自身が変わっていく実感が続ける力になります。

■ サボると錆びる
称号は消えませんが、やらない日が続くと錆びていき、5日空くと1段階下がります。今日やれば、輝きはすぐに戻ります。

■ 月1回の休息チケット
どうしても無理な日は休息にできます。サボり扱いにならず、称号もストリークも守られます。

■ 称号カードを共有
「あなたは今 ◯◯」の称号カードを画像にして、SNSに共有できます。

■ 毎日の習慣を、タップひとつで記録
チェックするだけで達成を記録。連続日数（ストリーク）が表示されるので、「続けている実感」がモチベーションになります。

■ 回数で数える習慣にも対応
「水を1日8杯」のように、回数を数えるタイプの習慣も管理できます。

■ 「週3回」のような習慣もOK
毎日でなくていい習慣は、週あたりの回数で設定できます。曜日を決めずに、自分のペースで続けられます。

■ やり忘れは、あとから記録
カレンダーから過去の日をタップして、後から達成を記録できます。うっかりチェックし忘れても大丈夫。

■ 続けたくなる仕組み
達成でレベルアップ、12種類の実績バッジを解除。週間グラフやカレンダーで、がんばりが目に見えます。

■ お休みもできる
旅行や体調不良のときは「一時停止」。記録を消さずにお休みして、いつでも再開できます。

■ 忘れないリマインド
設定した時刻に、未完了があればお知らせします。

■ その他
・ダークモード対応（自動切替）
・データのバックアップ / 復元
・ドラッグで並べ替え
・完全オフライン動作。データは端末内にのみ保存され、外部に送信されません。
```

**キーワード（100字以内・カンマ区切り）**
```
習慣,習慣化,称号,継続,ストリーク,習慣管理,タスク,todo,ルーティン,日課,目標,トラッカー,自己成長
```

**カテゴリ**
- プライマリ: 仕事効率化
- セカンダリ: ヘルスケア/フィットネス

**年齢制限**: 4+

### プライバシー情報（App Store Connect「App のプライバシー」）

- **データを収集しません** を選択してください。
- 理由: 本アプリは通信機能を持たず、すべてのデータは端末内（localStorage）にのみ保存されます。アナリティクス・広告・トラッキングは一切ありません。
- アプリにはプライバシーマニフェスト（`ios/App/App/PrivacyInfo.xcprivacy`）を入れてあります。内容は「トラッキングなし・収集データなし」と、端末内の保存に使う機能の利用理由（UserDefaults: アプリ自身のデータの保存）です。あわせて `Info.plist` に「暗号化を使っていない」（`ITSAppUsesNonExemptEncryption = NO`）を設定済みのため、アップロードのたびの暗号化（輸出コンプライアンス）の質問は出ません

## 5. 審査で見られやすい点

Appleガイドライン **4.2（最低限の機能）** について、本アプリは以下を満たしています。申請時の備考欄に記載すると安全です。

- 完全オフラインで動作する自立したアプリ（Webサイトの単なる表示ではない）
- 端末内にデータを保存し、継続的に利用する設計
- ネイティブのローカル通知・触覚フィードバックを実装
- 写真への追加の許可は、称号カードを「写真」に保存するときだけ求めます（説明文を設定済み）

## 6. アプリ内容を修正したい場合

アプリ本体は 1つ上のフォルダの `index.html` です。修正後、このフォルダで：

```bash
npm run sync
```

を実行するとiOSプロジェクトに反映されます。その後Xcodeで再ビルドしてください。
